# Pilota Godot — Evocazione epica

Versione web di una prova tecnica: l'evocazione di un mostro di Livello 7+ rifatta in Godot 4.7.2
(renderer Compatibility, WebGL 2, senza thread). Due carte del set WW1 (Francesco Baracca, Godwin von Brumowski)
sul campo di battaglia notturno della Grande Guerra.

Comandi: **Spazio** rigioca · **Tab** cambia carta · **S** rallentatore (anche con i bottoni in basso).
In alto a destra: fps medi, 1% peggiore, riepilogo dell'ultimo ciclo e GPU.

Repository temporaneo, solo per provare la scena su PC e telefono.
